# Panes

Gestionnaire de fenêtres macOS façon Windows / Ubuntu : snap aux bords, bordure partagée entre fenêtres collées, prise en charge des écrans verticaux.

Le besoin complet est décrit dans [BESOIN.md](BESOIN.md).

## Démarrer

```sh
brew install xcodegen   # si besoin
xcodegen generate
open Panes.xcodeproj
```

Au premier lancement, autoriser Panes dans **Réglages Système > Confidentialité et sécurité > Accessibilité**.
