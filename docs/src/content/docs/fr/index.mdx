  <Card title="Glisser vers un bord" icon="rocket">

  </Card>
  <Card title="Raccourcis façon Win + flèches" icon="pencil">
    `⌃⌥` + flèches pour les moitiés, avec passage à l'écran voisin en appuyant de nouveau. [Voir les raccourcis](/fenestra/fr/guide/keyboard/).
  </Card>
  <Card title="Écran vertical" icon="laptop">
    Sur un écran en portrait, le découpage principal est haut / bas. [Détails](/fenestra/fr/guide/vertical-display/).
  </Card>
  <Card title="Bordure partagée" icon="random">
    Tirez la bordure commune de deux fenêtres collées : les voisines suivent. [Comment ça marche](/fenestra/fr/guide/shared-border/).
  </Card>
  <Card title="Snap Layouts" icon="star">
    Laissez le pointeur sur le bouton vert d'une fenêtre et cliquez sur une zone dans une palette de dispositions. [Voir Snap Layouts](/fenestra/fr/guide/snap-layouts/).
  </Card>
  <Card title="Snap Assist" icon="puzzle">
    Collez une fenêtre sur une moitié, à la souris ou au clavier, et choisissez-en une autre pour remplir l'espace libre, avec des miniatures en option. [Voir Snap Assist](/fenestra/fr/guide/snap-assist/).
  </Card>
  <Card title="Multi-écrans" icon="external">
    Chaque écran a ses zones et son orientation ; envoyez une fenêtre de l'un à l'autre d'un raccourci. [Détails](/fenestra/fr/guide/multiple-displays/).
  </Card>
